# FakeSlots
Client-side-only cosmetic overlay for Fabric 1.21.11. It changes what your own screen draws in container GUIs and sends nothing to the server.
Commands: `/fakeslots toggle`, `/fakeslots layout dropper|off`, `/fakeslots item <id>`, `/fakeslots title <text>`.
Intended for clearly labeled staged/educational content. Do not use it to deceive anyone.
